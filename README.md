## 🔍 Technical SEO & Optimization Features

* **Crawlability:** Fully validated [`robots.txt`](robots.txt) and [`sitemap.xml`](sitemap.xml).
* **Semantic HTML5:** Native landmark tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **Microdata & JSON-LD:**
  * `schema.org/Hackathon` & `Event` (on `index.html`)
  * `schema.org/FAQPage` (on `faq.html`)
  * `schema.org/BreadcrumbList` (on all subpages)
  * `schema.org/Organization` (in footer)
* **Performance:** Pure vanilla HTML/CSS/JS (Zero runtime framework overhead; loads in < 400ms).
* **WCAG 2.1 AA Compliant:** Accessible contrast ratios across all cards and text components.
